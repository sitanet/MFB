How It Works

Example: API Cost = ₦150, Merchant Charge = ₦200

  1. Merchant requests NIN verification
  2. System checks merchant has ₦200+ balance
  3. ₦200 is debited from merchant's float
  4. ₦150 credited to API Cost GL (expense)
  5. ₦50 credited to Profit GL (income)
  6. NIN API is called and results shown
